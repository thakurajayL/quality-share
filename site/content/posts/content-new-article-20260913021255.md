summary: OpenAI has launched the Agents API in public beta, enabling developers to easily create production-ready agents with a single API call. The API offers a range of features including context management, tool search, programmatic tool calling, and multi-agent support. Developers can use the open-source Codex harness and access the API at no extra cost, only paying for tokens and tools used. Feedback from the public beta will be used to enhance the API for wider availability.
