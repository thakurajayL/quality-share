summary: The article discusses GenRec, a recommendation system at Netflix that utilizes large language models to improve recommendations. GenRec verbalizes user histories and context as text, post-trains a Netflix-adapted LLM for ranking, and incorporates reward signals for long-term member value and business goals. It achieves significant improvements in online metrics compared to traditional production rankers, while using fewer labeled examples and input signals. GenRec's training framework involves adapting an open-source LLM on Netflix data and post-training it for ranking-specific objectives. The model is trained with a multi-objective loss that combines ranking, language modeling, and reward-weighted training. The architecture includes a decoder-only Transformer with a catalog-aware scoring head that ranks Netflix in-catalog items based on user preferences and context. GenRec is a recommendation ranker at Netflix that uses a large language model for personalization, outperforming a production ranker with fewer input signals and labeled examples. It shows promise as a more cost-effective and scalable recommendation system at Netflix.
