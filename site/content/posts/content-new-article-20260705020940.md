summary: The article discusses the development of GenPage, an end-to-end generative model for personalized homepage construction on Netflix. The model uses a prompt-response paradigm to generate homepage layouts based on user history and request context, aiming to optimize user satisfaction and scalability. GenPage utilizes a decoder-only transformer architecture, pretraining, and post-training with reinforcement learning to improve user engagement and reduce serving latency. The model incorporates strategies like context injection and semantic embedding fusion to address challenges like cold start and incremental training. Offline experiments and online A/B testing showed significant improvements in user engagement metrics and reduced serving latency, highlighting the effectiveness of GenPage in generating personalized recommendations.
